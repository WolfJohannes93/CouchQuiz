# CouchQuiz

Dieses Projekt bietet eine einfache Grundstruktur für ein Live-Quiz. Das Frontend basiert auf React und das Backend auf Node.js mit Socket.io.

## Ordnerstruktur

- `server` – Node.js/Socket.io-Backend
- `client` – React-Frontend

## Erste Schritte

1. Wechsel in `server` und installiere die Abhängigkeiten: `npm install`.
2. Starte das Backend mit `node server.js`.
3. Wechsel in `client` und installiere die Abhängigkeiten: `npm install`.
4. Starte ein statisches HTTP-Server wie `npx serve -s public` oder öffne `public/index.html` direkt im Browser.
